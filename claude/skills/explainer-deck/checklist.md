# Explainer deck checklist

Run this once before the last publish and fix every failure.

## Story

- [ ] The titles alone tell the story, in one sentence-case grammar.
- [ ] The deck teaches before it reports: mechanism first, results last.
- [ ] Every mechanism with three or more ordered parts is a build sequence.
- [ ] One worked example runs through each build, and its invented values say "illustrative".

## Claims

- [ ] Every number on a slide is in a source, with the same value and unit.
- [ ] No slide states something the audience already knows.
- [ ] No column or label gives a verdict from a threshold you chose. Spreads are shown as
      a median and a 90th percentile.
- [ ] Every coined term is defined where it first appears, with its range in brackets.
- [ ] No label means two things on one slide or across a build.
- [ ] A staged plan says what gates each stage and does not promise every stage.

## Layout

- [ ] Every content slide's header sits at the same position, and every title is 49
      characters or fewer.
- [ ] Every pinned element ends at or above y 952.
- [ ] Every box is wider than its longest word at its font size.
- [ ] Connectors run edge midpoint to edge midpoint, and no label sits on a line.
- [ ] Every build element keeps its `id` and position across slides.
- [ ] The one takeaway per section sits in the orange callout box.
